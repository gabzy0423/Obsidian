description: A relentless interview to sharpen a plan or design, which also creates docs (ADR's and glossary) as we go.

Read `../grilling/SKILL.md` and `../domain-modeling/SKILL.md` relative to this skill's directory, then apply both to the requested topic. Codex does not need a separate Skill tool for this.

Read the active project's instructions and existing requirements first. Ask only about unresolved decisions; revisit settled answers only when evidence conflicts. Keep the session within the requested feature or decision.

This workflow clarifies requirements and edits project documentation; it does not implement application code. At the end, summarize agreed rules and remaining questions. Pass those decisions to the project's implementation workflow when the user requests implementation; do not repeat the interview or replace its verification gates.
