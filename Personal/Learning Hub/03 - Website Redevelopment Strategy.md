# 03 — Website Redevelopment Strategy

## The Learning Lab — Website Redesign & Redevelopment

- **Document Type:** Website Redevelopment Strategy & Content Blueprint
- **Project Status:** Planning and Design
- **Primary Reference:** [The Foundry Lab](https://thefoundrylab.com/)
- **Secondary Reference:** Provided HTML Concept Prototype
- **Project Scope:** Public-Facing Corporate Website Prototype

---

## 1. Document Overview

This document defines the proposed redevelopment strategy for The Learning Lab's corporate website.

Building upon the project overview and existing website audit, it establishes the recommended information architecture, website pages, content organization, navigation experience, and visual design direction.

The redevelopment will consolidate the organization's existing website content with selected design concepts from the provided HTML prototype.

The objective is to create a unified corporate website that presents The Learning Lab's identity, learning methodology, signature training programs, and corporate learning solutions through a clear and consistent digital experience.

The project will focus on frontend website design and interactive prototyping. It will not introduce authentication, enrollment, learning management, HRIS backend functionality, or other complex operational systems.

## 2. Redevelopment Vision

### 2.1 Vision Statement

To establish a modern, accessible, and cohesive corporate website that serves as the central destination for discovering The Learning Lab's professional development programs, learning philosophy, and corporate training solutions.

### 2.2 Strategic Direction

The proposed redevelopment will be guided by five principles.

#### Content-Centered Design

Website content will determine the structure and purpose of each page. Visual elements will support communication rather than compete with it.

#### Centralized Information

Related information will be organized into logical sections and dedicated pages, reducing unnecessary repetition and improving discoverability.

#### Consistent User Experience

Navigation, typography, layouts, and interactions will follow shared design standards.

#### Professional Brand Presentation

The website will reflect the organization's established identity while adopting a more contemporary and engaging visual direction.

#### Practical Prototype Development

The website prototype will demonstrate meaningful frontend interactions without introducing unnecessary backend functionality.

## 3. Website Consolidation Strategy

The redevelopment will combine two primary references.

### 3.1 Existing Website — Content Foundation

The existing website will remain the authoritative reference for official organizational information.

Content to preserve includes:

- Organization background and identity
- Learning philosophy
- Four-element learning methodology
- Five signature learning categories
- Verified course titles and descriptions
- Approved corporate learning services
- Official contact information

### 3.2 HTML Prototype — Design Reference

The HTML prototype will contribute relevant presentation and interaction concepts.

Elements considered for adaptation include:

- Modern homepage hero
- Signature program cards
- Structured content sections
- Contemporary typography
- Responsive navigation
- Frequently Asked Questions
- Inquiry interface
- Calls to action
- Footer organization

Prototype-only business claims or additional services will not automatically become official website content.

### 3.3 Consolidation Rules

| Rule | Description |
|---|---|
| Preserve | Maintain verified content and organizational identity |
| Improve | Enhance presentation, readability, and usability |
| Merge | Consolidate related or repetitive content |
| Introduce | Add justified pages and frontend components |
| Validate | Confirm business information before publication |
| Exclude | Remove unsupported or out-of-scope functionality |

The final website should not be a direct copy of either reference. It should represent a deliberate redevelopment based on the strengths of both.

## 6. Page-by-Page Content Blueprint

The following sections define the proposed content structure for each major website page.

**Purpose**

Introduce The Learning Lab, communicate its value proposition, highlight signature learning programs, and direct visitors toward relevant information.

**Proposed sections**

| Order | Section | Content |
|---|---|---|
| 01 | Navigation Header | Logo, navigation links, contact CTA |
| 02 | Hero | Headline, supporting description, primary CTA |
| 03 | Organization Introduction | Brief overview of The Learning Lab |

| 09 | FAQs | Selected common questions |
| 10 | Final CTA | Encourage visitors to request information |
| 11 | Footer | Navigation, contact details, supporting links |

- **Secondary CTA:** Contact Us

The homepage should act as a gateway to the website rather than contain every available course description.

### 6.2 About Us

Introduce the organization and explain its professional development philosophy.

1. Page introduction and headline
2. Company background
3. Organizational purpose
4. Learning philosophy
5. Learning approach preview
6. Organizational differentiators
7. Contact CTA

Mission, vision, and team information may be added if official content is available and approved.

### 6.3 Our Learning Approach

**Purpose**

Explain how The Learning Lab delivers engaging and practical learning experiences.

**Proposed sections**

1. Page introduction
2. Learning philosophy overview
3. Brain Engagers
4. Co-Active Learning
5. Retrieval Practice
6. Play Space
7. Practical application of the methodology
8. Related training programs
9. Contact CTA

Each learning element should have a consistent presentation with a title, concise description, and relevant visual support.

### 6.4 Our Programs

**Purpose**

Provide a centralized directory of The Learning Lab's signature training programs.

| Section | Content |
|---|---|

Provide detailed information about a specific training course.

| Section | Content |
|---|---|

### 6.7 Our Solutions

**Purpose**

Present The Learning Lab's verified corporate training and learning development services.

**Proposed sections**

1. Page introduction
2. Corporate learning solutions overview
3. Tailored training solutions
4. Learning and development approach
5. Engagement or consultation process
6. Relevant signature programs
7. Contact CTA

**Content validation requirement**

The HTML prototype includes additional concepts such as HRIS Customization and CADS Competency Platform.

These should not be presented as official services unless approved by The Learning Lab.

The Our Solutions page should initially focus on verified training-related offerings.

### 6.8 Contact Us

**Purpose**

Provide visitors with a clear way to contact the organization and request information.

**Proposed sections**

1. Contact page introduction
2. Official contact information
3. Inquiry form interface
4. Location information, if verified
5. Frequently asked contact questions
6. Footer

**Proposed inquiry fields**

| Field | Type |
|---|---|

| Email Address | Email |

| Inquiry Type | Selection |

### 6.9 Frequently Asked Questions

**Purpose**

Provide concise answers to common questions about training programs and inquiries.

Potential topics include:

- Available training programs
- Course information
- Corporate training arrangements
- Training delivery formats
- Contact and consultation process

All answers must be based on verified organizational information.

FAQs may be incorporated into the homepage and relevant pages instead of requiring a separate page.

## 8. Navigation and User Experience Strategy

### 8.1 Primary User Journey — Program Discovery

```text
Homepage
   ↓
Our Programs
   ↓
Select Program Category
   ↓
Browse Available Courses
   ↓
View Course Details
   ↓
Contact / Request Information
```

This journey supports visitors who already know the type of training they need.

### 8.2 Secondary User Journey — Organization Discovery

```text
Homepage
   ↓
About Us
   ↓
Our Learning Approach
   ↓
Explore Programs
   ↓
Contact Us
```

This journey supports visitors who want to understand the organization before exploring its offerings.

### 8.3 Corporate Client Journey

```text
Homepage
   ↓
Our Solutions
   ↓
Review Corporate Training Information
   ↓
Explore Relevant Programs
   ↓
Contact Us
```

This journey supports organizational decision-makers seeking learning and development solutions.

### 8.4 Navigation Principles

The redesigned website should:

- Use clear and familiar navigation labels.
- Keep primary navigation consistent across pages.
- Provide visible links between related content.
- Use breadcrumbs on deeper program and course pages where useful.
- Maintain clear calls to action.
- Avoid unnecessary navigation levels.
- Provide an accessible mobile navigation experience.

## 9. UI/UX Design Direction

The visual direction will adapt relevant elements from the provided HTML prototype while maintaining a professional corporate identity.

### 9.1 Design Principles

**Clarity**

Content should be easy to scan and understand.

**Consistency**

Related pages and components should follow shared visual standards.

**Accessibility**

Text, controls, and navigation should be readable and usable.

**Responsiveness**

Layouts should adapt to desktop, tablet, and mobile devices.

**Purposeful Design**

Visual elements should support the content rather than introduce unnecessary decoration.

### 9.2 Proposed Color Direction

The following palette is based on the supplied HTML prototype.

| Color | Hex | Intended use |
|---|---|---|
| Deep Purple | `#281052` | Primary brand color |
| Mint | `#55DFBE` | Secondary accent |
| Warm Orange | `#FFBD59` | Supporting accent |
| Coral | `#FF6875` | Limited highlights |
| Off-White | `#F8F6FC` | Light backgrounds |

The final palette should be reviewed against the organization's official brand assets.

Color combinations must also be evaluated for sufficient text contrast.

### 9.3 Typography

The prototype uses Outfit and DM Sans.

A proposed typography system may use:

- Outfit: Headings and display text
- DM Sans: Body text, navigation, and interface labels

Typography should establish a clear hierarchy between page titles, section headings, descriptions, and supporting information.

### 9.4 Layout Guidelines

The website should use:

- Consistent content widths
- Clear section spacing
- Responsive grids
- Readable text line lengths
- Consistent card dimensions
- Balanced visual hierarchy
- Appropriate whitespace

The design should avoid overcrowded sections and excessive decorative elements.

### 9.5 Reusable Components

| Component | Intended use |
|---|---|

| Footer | Contact details and supporting links |
| Hero | Main page introductions |
| Program Card | Learning category presentation |
| Course Card | Individual course previews |
| CTA Section | Contact and inquiry prompts |
| Breadcrumbs | Deeper page navigation |

## 10. Responsive Design Strategy

The website should provide a consistent browsing experience across screen sizes.

### Desktop

- Full primary navigation
- Multi-column program grids
- Spacious layouts
- Clear visual hierarchy

### Tablet

- Adaptive navigation
- Reduced grid columns
- Flexible content spacing
- Appropriately scaled typography

### Mobile

- Collapsible navigation
- Single-column content where appropriate
- Readable text
- Accessible touch targets
- Clearly visible calls to action

Responsive behavior should be validated through actual browser testing rather than assumed from visual design alone.

## 12. Content Strategy

### 12.1 Content Priorities

The redesigned website should prioritize:

1. Organizational clarity
2. Signature program discovery
3. Accurate course information
4. Learning methodology
5. Corporate training solutions
6. Contact accessibility

### 12.2 Content Writing Guidelines

Website content should be:

- Clear and professional
- Concise but informative
- Consistent in terminology
- Relevant to the target audience
- Easy to scan
- Accurate and verifiable

### 12.3 Content Ownership

Official business information should be validated by the organization before final publication.

The development team may recommend structural and editorial improvements but should not introduce unsupported claims.

### 12.4 Content Reuse

Important information may be summarized across multiple pages, but detailed content should have one primary location.

For example:

- The homepage introduces signature programs.
- The Programs page lists categories.
- Category pages list courses.
- Course detail pages contain complete course information.

This reduces duplication while maintaining useful navigation pathways.

| 3 | Programs | Directory and category pages |

| 8 | Quality Review | Content, navigation, accessibility, consistency |

Development should prioritize complete and coherent user journeys over unnecessary visual or technical complexity.

## 14. Prototype Acceptance Criteria

The redevelopment prototype should satisfy the following criteria.

### Content

- Verified organizational information is preserved.
- All five signature categories are represented.
- Course information follows consistent templates.
- Unverified claims are not presented as official facts.

### Navigation

- All planned pages are accessible.
- Internal links lead to the correct destinations.
- Visitors can navigate between categories and course details.
- Contact information is easy to locate.

### UI/UX

- Pages follow a consistent visual design.
- Typography and spacing remain readable.
- Interactive elements provide appropriate feedback.
- Navigation works on mobile devices.

### Responsiveness

- Content adapts to desktop, tablet, and mobile layouts.
- Text and cards remain readable.
- Navigation remains usable.
- No essential content is inaccessible because of layout issues.

### Prototype Functionality

- Page navigation works.
- Course cards open their intended destinations.
- FAQ interactions function where implemented.
- Inquiry interfaces demonstrate appropriate frontend behavior.
- No backend functionality is falsely represented as operational.

These approvals will help ensure that the redesigned website accurately represents The Learning Lab.

## 16. Final Redevelopment Direction

The Learning Lab's website redevelopment will focus on consolidating existing organizational content and selected HTML prototype elements into a unified corporate website.

The proposed website will emphasize:

- Clear information architecture
- Centralized signature programs
- Consistent course presentation
- Stronger organizational storytelling
- Professional visual design
- Responsive navigation
- Straightforward contact pathways

The redevelopment will remain focused on a public-facing website prototype rather than a learning management or enterprise software platform.

The expected outcome is a modern, cohesive, and content-driven website prototype that provides a practical foundation for The Learning Lab's future digital presence.
